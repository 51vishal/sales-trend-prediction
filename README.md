# 📌 About the Project

**Sales Trend Prediction** is a machine learning project developed to predict
future sales trends using **Simple Linear Regression**.

The project analyzes historical sales data and incorporates human behavioral
and external factors that may influence sales patterns.

The proposed system introduces a **Human Behavior–Adjusted Sales Trend Model**
that considers factors such as:

- 🎉 Festival intensity
- 💰 Salary effect
- 📅 Weekend type
- 🏪 Local events
- 👥 Number of visitors

The system also provides a user-friendly interface for entering input values
and viewing predicted sales results.

---

# 🎯 Problem Statement

Accurate sales prediction is an important challenge for businesses in
dynamic and competitive markets.

Traditional prediction systems mainly depend on historical numerical data
and may not consider factors such as customer preferences, seasonal trends,
buying behavior, and market demand variations.

This project addresses these limitations by combining **Simple Linear
Regression** with human behavior factors to provide more practical and
user-friendly sales predictions.

---

# 🎯 Objectives

The main objectives of this project are:

- To design a user-friendly interface for sales prediction
- To integrate human behavior into the prediction model
- To implement Simple Linear Regression
- To perform data preprocessing
- To select relevant prediction features
- To generate future sales predictions
- To provide visual outputs
- To support better business decision-making

# 🧠 Human Behavior Factors

The model considers several factors that can influence sales.

| Feature | Description |
|---|---|
| 🎉 Festival Intensity | Level of festival impact on purchasing |
| 💰 Salary Effect | Influence of customer purchasing power |
| 📅 Weekend Type | Weekday or Weekend |
| 🏪 Local Event | Presence of a local event |
| 👥 Number of Visitors | Number of visitors/customers |

These factors are used to understand how human behavior and external
conditions can affect sales trends.
